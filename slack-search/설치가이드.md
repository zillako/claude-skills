# Slack Search Skill 설치 가이드

Slack Search Skill을 처음 설치하시나요? 이 가이드는 5단계로 설치를 완료할 수 있도록 구성되어 있습니다.

**예상 설치 시간**: 5-10분 (Slack App 생성 제외)

---

## 1. 사전 준비 사항

설치하기 전에 다음 사항을 확인하세요.

### 1.1 지원 운영체제

다음 운영체제를 지원합니다:

| OS | 지원 여부 | 비고 |
|----|---------|------|
| macOS 13+ (Ventura, Sonoma) | ✅ 완벽 지원 | 권장 |
| Ubuntu 20.04+ | ✅ 완벽 지원 | Linux 권장 |
| Debian 11+ | ✅ 완벽 지원 | - |
| Windows 11 (WSL2) | ✅ 지원 | WSL2 필수 (WSL1 비권장) |
| Windows 네이티브 | ❌ 미지원 | WSL2로 설치하세요 |

**Windows WSL2 확인 방법**:
```bash
wsl --list --verbose
```

WSL2를 사용 중인지 확인하고, WSL1이면 업그레이드하세요.

### 1.2 필수 도구

**반드시 필요한 것**:
- **curl** (인터넷 요청용)
- **bash 4.0 이상** (대부분 기본 설치됨)
- **Claude Code** (최신 버전)

**선택 사항**:
- **jq** (JSON 파싱용, 없으면 자동으로 대체 방법 사용)

설치 환경을 확인하세요:

```bash
# curl 확인
curl --version

# bash 버전 확인
bash --version

# jq 확인 (선택)
jq --version
```

출력이 보이면 설치된 것입니다. 없다면 아래를 참고하세요.

### 1.3 도구 설치하기 (필요한 경우)

**macOS** (Homebrew 사용):
```bash
brew install curl bash jq
```

**Ubuntu/Debian**:
```bash
sudo apt update
sudo apt install curl bash jq
```

### 1.4 Claude Code 확인

Claude Code가 설치되어 있는지 확인하세요. Terminal에서 다음 명령어를 실행합니다:

```bash
which claude
```

경로가 출력되면 설치된 것입니다. 없으면 [Claude Code 설치 가이드](https://claude.ai/docs)를 참고하세요.

## 2. Slack App 생성

Slack Skill을 사용하려면 먼저 Slack App을 생성하고 User Token을 발급받아야 합니다.

### 2.1 Slack App 생성 페이지 접속

[https://api.slack.com/apps](https://api.slack.com/apps) 에 접속합니다.

Slack에 로그인하면 자신의 App 목록이 보입니다.

### 2.2 새 App 생성

**방법 1: "Create New App" 버튼**
1. 페이지 우측 상단의 "Create New App" 버튼을 클릭
2. "From scratch" 옵션 선택
3. App 이름 입력 (예: `slack-search-bot`)
4. Workspace 선택
5. "Create App" 버튼 클릭

**상세 가이드**: Slack 공식 문서 [앱 생성하기](https://api.slack.com/start/quickstart)를 참고하세요.

### 2.3 OAuth Scopes 추가

생성된 앱의 설정 페이지로 이동합니다.

좌측 메뉴에서 **"OAuth & Permissions"** 를 클릭합니다.

**"User Token Scopes"** 섹션에서 다음 권한(Scopes)을 추가합니다:

필요한 권한 체크리스트:

- [ ] `channels:history` - 공개 채널 메시지 히스토리 읽기
- [ ] `channels:read` - 공개 채널 정보 읽기
- [ ] `groups:history` - 비공개 채널 메시지 히스토리 읽기
- [ ] `groups:read` - 비공개 채널 정보 읽기
- [ ] `im:history` - DM(Direct Message) 히스토리 읽기
- [ ] `im:read` - DM 정보 읽기
- [ ] `mpim:history` - 그룹 DM 히스토리 읽기
- [ ] `mpim:read` - 그룹 DM 정보 읽기
- [ ] `search:read` - Slack 검색 기능 사용
- [ ] `users:read` - 사용자 정보 읽기
- [ ] `users:read.email` - 사용자 이메일 읽기

각 권한을 추가하려면:
1. "Add an OAuth Scope" 버튼 클릭
2. 권한 이름 선택
3. 자동으로 추가됨

모든 권한을 추가하면 페이지가 자동으로 저장됩니다.

### 2.4 Workspace에 App 설치

같은 페이지의 **"OAuth Tokens for Your Workspace"** 섹션을 찾습니다.

"Install to Workspace" 또는 "Reinstall to Workspace" 버튼을 클릭합니다.

설치 확인 창이 나타나면 "허용" 또는 "Allow"를 클릭합니다.

### 2.5 User Token 복사

설치 후, **"User OAuth Token"** 이 표시됩니다.

토큰 형식 예:
```
xoxp-YOUR-WORKSPACE-ID-YOUR-USER-ID-YourSecretToken
```

**`xoxp-`로 시작하는** 긴 문자열입니다.

토큰 우측의 **"Copy"** 버튼을 클릭하여 복사합니다.

**주의**: 이 토큰을 절대 공개하지 마세요! Git에 커밋하거나 다른 사람과 공유하면 안 됩니다.

## 3. Slack Search Skill 설치

### 3.1 패키지 다운로드

GitHub Release 페이지에서 패키지를 다운로드합니다.

Terminal을 열고 다운로드 폴더로 이동합니다:

```bash
cd ~/Downloads
```

다음 명령어로 최신 버전을 다운로드합니다:

```bash
wget https://github.com/zillako/slack-search-skill/releases/download/v1.1.0/slack-search-v1.1.0.tar.gz
```

또는 `curl` 을 사용하세요:

```bash
curl -L -O https://github.com/zillako/slack-search-skill/releases/download/v1.1.0/slack-search-v1.1.0.tar.gz
```

다운로드 완료 후 다음으로 진행합니다.

### 3.2 패키지 압축 해제

다운로드된 파일을 압축 해제합니다:

```bash
tar -xzf slack-search-v1.1.0.tar.gz
```

압축이 풀린 폴더로 이동합니다:

```bash
cd slack-search-v1.1.0
```

폴더 구조를 확인하려면:

```bash
ls -la
```

다음 파일들이 보이면 정상입니다:

```
install.sh
setup.sh
verify.sh
uninstall.sh
SKILL.md
설치가이드.md
README.md
```

### 3.3 Installer 실행

다음 명령어로 설치를 시작합니다:

```bash
./install.sh
```

설치 중 다음과 같은 과정이 진행됩니다:

1. **의존성 확인** - curl, bash 버전 확인
2. **기존 설치 감지** - 이미 설치되어 있는지 확인
3. **파일 복사** - `~/.claude/skills/slack-search/` 에 파일 복사
4. **setup.sh 실행** - Token 설정 (다음 단계 참고)
5. **설치 검증** - verify.sh로 설치 확인

모든 과정이 완료되면 "Installation complete!" 메시지가 표시됩니다.

**문제가 발생한 경우** (다음 섹션의 "문제 해결"을 참고하세요):

```bash
./install.sh --help
```

도움말을 보려면 위 명령어를 실행하세요.

## 4. Token 설정

### 4.1 setup.sh 실행

`install.sh` 가 자동으로 `setup.sh` 를 실행합니다. 만약 건너뛰었다면 수동으로 실행하세요:

```bash
./setup.sh
```

### 4.2 Token 입력

다음과 같은 프롬프트가 나타납니다:

```
Enter your Slack User Token (starts with xoxp-):
```

2단계에서 복사한 Token을 붙여넣습니다:

```
xoxp-YOUR-WORKSPACE-ID-YOUR-USER-ID-YourSecretToken
```

Token을 입력하고 Enter를 누릅니다.

**보안**: Terminal에 입력할 때 Token이 화면에 보이지 않을 수 있습니다. 이는 정상입니다.

### 4.3 Workspace 이름 입력

다음 프롬프트가 나타납니다:

```
Enter your Slack Workspace name (e.g., my-company):
```

Slack Workspace 이름을 입력합니다. 예:

```
my-company
```

또는 팀 이름을 입력해도 됩니다.

### 4.4 연결 확인

설정이 완료되면 Slack API와의 연결을 확인합니다:

```
Testing connection to Slack API...
✓ Connection successful!
✓ Workspace: my-company
```

이 메시지가 보이면 설치가 완료된 것입니다.

**연결 실패한 경우** (다음 섹션의 "문제 해결"을 참고하세요):
- Token이 올바른지 확인
- Token에 필요한 권한이 모두 추가되었는지 확인
- 네트워크 연결을 확인

설치가 제대로 되었는지 확인하려면:

```bash
./verify.sh
```

다음과 같은 출력이 나타나면 성공입니다:

```
Slack Search Skill - Health Check
================================

Installed: YES
Version: 1.1.0
Config exists: YES
Token valid: YES
API connected: YES
Workspace: my-company

All checks passed!
```

**문제가 있는 경우**:
- 각 항목이 "NO"로 표시되면 해당 섹션의 문제 해결을 참고
- Exit code를 확인하세요 (다음 명령어):

```bash
./verify.sh
echo "Exit code: $?"
```

Slack 채널 목록 보여줘

또는:

```
Slack에서 "test" 검색해줘
```

Claude Code가 Slack 채널을 조회하거나 메시지를 검색하면 설치 완료입니다!

더 많은 예시는 [examples/sample-queries.md](./examples/sample-queries.md)를 참고하세요.

## 6. 문제 해결 (Troubleshooting)

설치 중 문제가 발생했나요? 다음 가이드를 참고하세요.

### 6.1 Token 오류

**증상**: "Invalid token" 또는 "Unauthorized" 에러

**원인**:
- Token을 잘못 복사했음
- Token이 만료되었음
- Token에 필요한 권한이 없음

**해결 방법**:

1. Slack 앱 설정 페이지 ([https://api.slack.com/apps](https://api.slack.com/apps)) 재방문
2. 자신의 App 선택
3. "OAuth & Permissions"에서 User Token 확인
4. Token이 "xoxp-"로 시작하는지 확인
5. Token 옆의 "Rotate" 버튼으로 새 Token 생성
6. 새 Token으로 `setup.sh` 다시 실행:

```bash
./setup.sh
```

### 6.2 "채널을 찾을 수 없음" 오류

**증상**: "Channel not found" 또는 "Unable to find channel"

**원인**:
- 채널명이 잘못되었음
- Token에 채널 접근 권한이 없음
- 채널이 삭제되었음

**해결 방법**:

1. Slack 앱 설정 페이지에서 다음 권한 확인:
   - `channels:read` (공개 채널)
   - `groups:read` (비공개 채널)

2. 정확한 채널명 확인:
   ```
   Slack에서 채널 목록 보여줘
   ```
   Claude Code에 위 쿼리를 입력하면 가능한 모든 채널 목록이 표시됩니다.

3. 채널명에 `#` 기호는 입력하지 마세요:
   ```
   ✓ engineering    (O)
   ✗ #engineering   (X)
   ```

### 6.3 Permission Denied 오류

**증상**: "Permission denied" 또는 "install.sh: permission denied"

**원인**: 스크립트에 실행 권한이 없음

**해결 방법**:

실행 권한을 추가합니다:

```bash
chmod +x install.sh setup.sh verify.sh uninstall.sh
```

그 후 다시 실행합니다:

```bash
./install.sh
```

### 6.4 Rate Limit 에러

**증상**: "rate_limited" 또는 "too many requests"

**원인**: Slack API 요청 한도 초과

**해결 방법**:

1. 몇 분 대기 후 다시 시도
2. 한 번에 많은 검색을 하지 마세요
3. 검색 범위를 좁게 지정 (예: 특정 날짜, 특정 채널)

더 많은 팁은 [examples/advanced-usage.md](./examples/advanced-usage.md)의 "Performance Tips" 섹션을 참고하세요.

### 6.5 "command not found: curl" 오류

**증상**: curl 명령어를 찾을 수 없음

**해결 방법**:

1. **macOS**:
   ```bash
   brew install curl
   ```

2. **Ubuntu/Debian**:
   ```bash
   sudo apt install curl
   ```

3. 설치 후 확인:
   ```bash
   curl --version
   ```

### 6.6 다른 스크립트 실행 오류

스크립트 실행 중 다른 오류가 발생한 경우:

1. 로그를 확인합니다:
   ```bash
   ./install.sh 2>&1 | tee install.log
   ```

2. 문제를 GitHub Issues에 보고합니다:
   - 로그 내용
   - 운영체제 및 버전
   - 설치 명령어

## 7. FAQ

일반적인 질문과 답변입니다.

### Q1. jq가 설치되어 있지 않습니다. 설치해야 하나요?

**A**: jq는 선택 사항입니다. `setup.sh` 과 `verify.sh` 는 jq가 없어도 동작합니다.
다만 jq가 있으면 JSON 처리가 더 빠릅니다.

설치하려면:
```bash
brew install jq          # macOS
sudo apt install jq      # Ubuntu/Debian
```

### Q2. 여러 Slack Workspace를 사용하고 싶습니다.

**A**: 현재 Slack Search Skill은 하나의 Workspace만 지원합니다.

여러 Workspace를 사용하려면:
1. 각 Workspace별로 Token을 따로 보관
2. Token 변경이 필요할 때마다 `setup.sh` 실행
3. 향후 버전(v2.0)에서 다중 Workspace 지원 예정

### Q3. Token을 변경하려면 어떻게 하나요?

**A**: 언제든지 `setup.sh` 를 다시 실행할 수 있습니다:

```bash
cd ~/.claude/skills/slack-search
./setup.sh
```

새 Token을 입력하면 기존 설정을 덮어씁니다.

### Q4. Token은 어디에 저장되나요?

**A**: Token은 `~/.slack/config.json` 파일에 저장됩니다.

```bash
cat ~/.slack/config.json
```

**보안**: 이 파일의 권한은 600으로 설정되어 다른 사용자는 읽을 수 없습니다.

```bash
ls -l ~/.slack/config.json
```

결과: `-rw-------` (소유자만 읽기/쓰기 가능)

### Q5. Skill을 완전히 제거하려면?

**A**: `uninstall.sh` 를 실행합니다:

```bash
cd ~/.claude/skills/slack-search
./uninstall.sh
```

선택사항:
- `--keep-config` 플래그로 Token 설정 유지 가능:
  ```bash
  ./uninstall.sh --keep-config
  ```

- `--force` 플래그로 확인 없이 제거:
  ```bash
  ./uninstall.sh --force
  ```

### Q6. 이전 버전을 사용 중인데 업그레이드하려면?

**A**: 새 버전을 다운로드하고 `install.sh` 를 업그레이드 옵션으로 실행합니다:

```bash
./install.sh --upgrade
```

또는 `-u` 단축 옵션:

```bash
./install.sh -u
```

업그레이드 시 Token 설정은 유지됩니다.

### Q7. Windows에서도 사용할 수 있나요?

**A**: Windows 네이티브는 지원하지 않습니다. 하지만 **WSL2** (Windows Subsystem for Linux 2)를 사용하면 됩니다.

WSL2 설정:
1. Windows Terminal 설치
2. WSL2 설치: https://docs.microsoft.com/en-us/windows/wsl/install
3. Ubuntu 설치 (Microsoft Store)
4. WSL Ubuntu에서 위의 설치 가이드 따라가기

### Q8. "xoxp-"로 시작하지 않는 Token을 받았습니다. 맞나요?

**A**: User Token은 반드시 `xoxp-` 로 시작해야 합니다.

다른 형태의 Token:
- `xoxp-` : User token (올바름)
- `xoxb-` : Bot token (search.messages API를 지원하지 않음)
- `xoxs-` : Custom scope token (작동하지 않음)

Slack 앱 설정에서 "OAuth & Permissions" 섹션의 **"User OAuth Token"** 을 사용하세요.

### Q9. 설치 후 즉시 작동하지 않습니다.

**A**: 다음을 확인하세요:

1. `verify.sh` 로 상태 확인:
   ```bash
   ./verify.sh
   ```

2. Claude Code 재시작 (완전히 종료 후 다시 열기)

3. Token 권한 재확인:
   - https://api.slack.com/apps 에서 앱 선택
   - "OAuth & Permissions"의 Bot Token Scopes 확인
   - 위의 "2.3 OAuth Scopes 추가" 섹션의 체크리스트 재검토

4. 네트워크 연결 확인:
   ```bash
   curl -I https://slack.com
   ```

### Q10. 기업 프록시 환경에서 설치할 수 있나요?

**A**: 프록시 설정 후 설치하세요:

```bash
curl -x [proxy-address]:[port] https://api.slack.com/api/auth.test \
  -H "Authorization: Bearer xoxb-..."
```

또는 환경 변수 설정:

```bash
export http_proxy=http://[proxy-address]:[port]
export https_proxy=http://[proxy-address]:[port]

./install.sh
```
